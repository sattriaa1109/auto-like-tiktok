# Auto Like TikTok Bot (Linux & PostgreSQL)

Bot otomatis untuk memberikan Like pada video TikTok menggunakan Selenium WebDriver, mendukung multi-profil (multi-akun), multi-browser (Chrome/Chromium & Firefox), dan database PostgreSQL.

## Struktur Folder
```text
.
├── src/
│   ├── __init__.py
│   ├── database.py
│   └── bot.py
├── main.py
├── requirements.txt
└── README.md
```

## Instalasi
1. Install dependensi Python:
   ```bash
   pip install -r requirements.txt
   ```
2. Jalankan program:
   ```bash
   python3 main.py
   ```
